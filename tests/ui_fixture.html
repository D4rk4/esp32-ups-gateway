Control Permissions · применятся после перезапуска

Schedules

Разовые / еженедельные

Active Schedule Status

Saved Schedule Rules · до 8 правил, после перезапуска

Разовое время вводится в UTC; недельные правила — во времени шлюза. Пропущенные и неопределённые после перезапуска операции не догоняются. Команда питания требует явного подтверждения.

Events

Ограниченный журнал в RAM. Фильтрация и экспорт выполняются шлюзом. Очистка журнала не удаляет очередь SNMP traps.

Data

Data Collection Interval

240 точек в RAM; история очищается при перезапуске. Недоступные значения сохраняются как null и образуют разрывы на графике.

Security

Local Users / Sessions

Administrator

Чтение, команды, настройки, экспорт секретов и перезапуск.

Device User / Operator

Чтение и разрешённые команды ИБП.

Read-Only User

Только состояние, журналы, время и сведения о возможностях.

Session Timeout

Пустой пароль сохраняет текущее значение. Новый пароль: 12–64 байта UTF-8. Имена активных пользователей должны различаться. Изменения доступа действуют после перезапуска.

Network

TCP/IP / SNMP

TCP/IP IPv4 · сохранённые настройки

SNMPv2c

Пустая community сохраняет текущую. Пустой адрес менеджера разрешает чтение с любого адреса сети. SNMPv3 не реализован.

Текущий IPv4: —. Изменение адреса вступит в силу после перезапуска; следующий вход может потребовать нового URL.

Notification

Traps / Syslog

SNMP Trap Receivers

Пустая community сохраняет текущую. Порт 1–65535; обычно 162. Тест использует действующие настройки.

Syslog Server · UDP RFC3164

UDP не подтверждает доставку получателю. Счётчик передачи не является подтверждением приёма. SMTP/email-уведомления в этой версии отсутствуют.

Quick Links

До 3 ссылок. Название: 32 байта; URL: 192 байта, только http:// или https://. Для удаления очистите оба поля.

Configuration File

Резервная копия JSON содержит пароли и SNMP community открытым текстом.

Импорт схемы 1 или 2; не более 12288 байт. Валидация выполняется до сохранения. После успешного импорта нужен перезапуск.

Reset / Reboot

Сброс возвращает функциональные настройки к исходным. Все учётные данные доступа и SNMP community сохраняются. Сетевые адреса можно сохранить отдельно.
