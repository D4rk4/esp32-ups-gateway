# ESP32 UPS Gateway 0.2.2

## Changes since 0.2.1

- Battery tests have their own `battery_test` output mode in `/api/status` (`ups.output_mode`). PowerNet `upsBasicOutputStatus` is 15 for a battery test with utility present, and 3 for a real outage during a test. The web UI shows "On Battery (Self-Test)".
- Header tabs are joined without gaps, and the load gauge turns yellow above 50 %.
- The README adds screenshots and a Tested hardware list.

## Upgrade and downloads

From 0.2.1, use an ordinary web upload or USB `update`; configuration is preserved. A gateway still on 0.2.0 needs the one-time USB step first. See [README section 7](https://github.com/D4rk4/esp32-ups-gateway/blob/v0.2.2/README.md#7-update-preserving-configuration) and [docs/OTA.md](https://github.com/D4rk4/esp32-ups-gateway/blob/v0.2.2/docs/OTA.md) for upgrade and flashing instructions.

Download all three `.bin` files and `SHA256SUMS.txt` into the same directory. To verify the images before flashing, run `sha256sum -c SHA256SUMS.txt` on Linux or `shasum -a 256 -c SHA256SUMS.txt` on macOS in that directory. `build-info.json` records image sizes and hashes. Assets are the CI-built flashable images; the gated source package from `tools/package_release.py` is not attached. GitHub provides source archives separately.

## Verification and limits

One lab board (ESP32-POE-16MB with MOD-RS232 and an Inform Sinus EVO 3000) ran a local build of the same sources. The 0.2.1 to 0.2.2 web update moved from `ota_1` to `ota_0`, preserved configuration and the event log, and reconnected with no poll errors. A short battery test started over SNMP reported status 15 during the test and 2 afterwards. A timed test was started and cancelled from the web UI, which showed "On Battery (Self-Test)".

The CI images are built from the tagged sources; the lab-tested image was built locally. Two local builds from the same sources in different directories produced different application hashes, so the CI image may differ from the lab-tested image. Automatic rollback, an upload from a real browser, and a fresh install or factory login on 0.2.2 were not verified.
